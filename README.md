# 🛡️ SafeFamily Guard - 家庭訊息真偽與防詐辨識助手

一個專為家庭成員（特別是長輩與親友）設計的互動式 HTML5 網頁應用程式，幫助家人快速辨識訊息真偽、破解詐騙陷阱，並提升防詐警覺。

---

## ✨ 核心特色與亮點功能

1. **互動式訊息診斷儀**：
   - 可直接貼上可疑簡訊或 LINE 訊息，或勾選特徵（如要求匯款、急迫感、不明短網址、飆股推薦、假檢警等）。
   - 系統即時計算詐騙風險指數（🔴 高風險 / 🟡 疑慮訊息 / 🟢 相對安全），並給出具體的警惕提示與建議作法。

2. **擬真簡訊/LINE 實戰模擬測驗**：
   - 收錄 5 大擬真對話題型（猜猜我是誰、點數到期簡訊、飆股社群、假檢警公文、大蒜檸檬假新聞）。
   - 答題後給予深入的漏洞解析與防衛訣竅，測驗結束頒發專屬榮譽稱號（如「火眼金睛 - 防詐神射手」）。

3. **8 大常見詐騙與假訊息案例庫**：
   - 涵蓋飆股投資、假冒親友、假檢警監管帳戶、網購解除分期、免費貼圖釣魚、神奇療效假新聞、假求職人頭帳戶、AI換臉聲音複製。

4. **查證五步驟與官方工具彙整**：
   - 整理「停、看、查、問、檢」萬用防詐口訣。
   - 一鍵連結 165 全民防詐網、LINE 官方查證、Cofacts 真的假的、MyGoPen 麥購騙、台灣事實查核中心。

5. **長輩友善與高對比介面**：
   - 支援「🔍 長輩大字體」與「◑ 高對比」閱讀模式，字體清晰、好閱讀。
   - 提供「家庭緊急聯絡卡」，長輩可預先填寫子女電話，方便遇疑慮時第一時間電話諮詢。

---

## 🚀 如何使用？

只需要在任意現代瀏覽器（Chrome, Safari, Edge, Firefox, 手機瀏覽器）中雙擊開啟 `index.html` 檔案即可直接運行，無需安裝任何後端伺服器或數據庫！

```bash
# 開啟方式（例如使用 Mac open 指令）
open /Users/emily/.gemini/antigravity/scratch/fact-check-family-guard/index.html
```

## 📂 專案檔案架構

- `index.html` - 主頁面 HTML5 結構與 accessibility 選項
- `css/style.css` - 現代 Glassmorphic 主題、長輩大字體模式、擬真聊天視窗樣式
- `js/data.js` - 案例庫、檢核規則、題庫與官方工具數據
- `js/diagnostic.js` - 風險分析與關鍵字比對邏輯引擎
- `js/quiz.js` - 互動式擬真聊天測驗引擎
- `js/app.js` - UI 控制器、事件綁定與模態彈窗處理
